# Sistema de Gestión Académica (SGA)

## Descripción del proyecto

Este repositorio contiene el diseño y modelado de la arquitectura de software de un Sistema de Gestión Académica (SGA), desarrollado como actividad académica de la asignatura Arquitectura de Software de la Corporación Unificada Nacional de Educación Superior (CUN).

## Objetivo

Diseñar una arquitectura que permita gestionar estudiantes, docentes, programas, asignaturas, grupos, matrículas, calificaciones y horarios, garantizando seguridad, integridad de la información, mantenibilidad y escalabilidad.

## Arquitectura propuesta

Se seleccionó una arquitectura de monolito modular con capas internas, utilizando como tecnologías de referencia React, Java con Spring Boot y PostgreSQL.

## Modelos del sistema

- Diagrama de casos de uso.
- Diagrama de componentes.
- Diagrama de despliegue.
- Modelo conceptual de datos.
- Diagrama de secuencia del proceso de matrícula.

## Uso de inteligencia artificial

Google AI Studio se utilizó como herramienta de apoyo para generar, revisar y mejorar la propuesta arquitectónica. Las sugerencias fueron evaluadas críticamente por el equipo.

## Alcance

El proyecto corresponde al diseño de la arquitectura del sistema. No incluye la implementación de una aplicación completamente funcional.
